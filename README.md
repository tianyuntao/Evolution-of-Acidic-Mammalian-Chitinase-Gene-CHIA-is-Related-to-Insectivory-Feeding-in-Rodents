# Evolution-of-Acidic-Mammalian-Chitinase-Gene-CHIA-is-Related-to-Insectivory-Feeding-in-Rodents
This dataset enables evolutionary analyses of Chia genes and pseudogenes in Rodentia. Via PAML 4.9 (codeml), branch, site and branch-site models were used to detect selective pressure (dN/dS) and lineage-specific adaptation, with curated alignments, trees, PAML files and dN/dS estimates provided for reproducibility and downstream inference.
Description of the data and file structure
This dataset supports evolutionary analyses of CHIA (acidic mammalian chitinase) genes and pseudogenes in Rodentia. Using PAML 4.9 (codeml), we conducted branch, site, and branch-site models to detect selective pressure (dN/dS) and lineage-specific adaptation. It includes curated alignments, phylogenetic trees, PAML control/output files, and dN/dS estimates for reproducibility and downstream evolutionary inference.

Files and variables
File: PAML_analysis.zip
Description: Key files are organized into three folders: raw_data (Rodents.fas, tree.txt), paml controls(branch_model.ctl, site_model.ctl, branch_site_model.ctl,), paml outputs (codeml model output .txt). Core variables include dN (nonsynonymous substitution rate), dS (synonymous substitution rate), ω (dN/dS, selective pressure indicator), 2ΔlnL (LRT statistic), and BEB posterior probability (site-specific selection probability).
